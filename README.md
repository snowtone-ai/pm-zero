# pm-zero

## 概要

エンジニアでなくても、AIと一緒に本物のソフトウェア開発を指揮・品質管理できるよう設計されたオペレーティングモデル（開発運用の仕組み）です。Claude CodeやCodex CLIなどのAIコーディングツールが参照する一連のドキュメント設計によって、指示の曖昧さをなくし、セッションをまたいでも文脈を失わず、品質を安定させます。v9.5ではCEO Agentがコーディネーターとしてワーカーエージェントを動的にオーケストレーション（指揮）する「Agent OS」を定義しています。

---

## 主な機能

- 「ビジョン（何を作るか）→タスク（次に何をするか）→実装→検証→引き継ぎ」の5段階フローでAIの行動を制御できる
- セッション終了後も状態・決定・ブロッカーをドキュメントに記録し、次セッションでAIが迷わず再開できる
- CEO Agentがタスク台帳（tasks.md）を管理し、複数のワーカーエージェントを並列・直列で調整できる
- タスク完了ごとにXP（経験値）が蓄積される成長追跡の仕組みが組み込まれている
- 完全な設計仕様書（pm-zero-knowledge-v9.5.md）として単一ファイルで配布・参照できる

---

## 技術スタック

AI・外部API：Claude Code、Codex CLI（AIコーディングエージェント）

---

## アーキテクチャの特徴

- ドキュメント（`vision.md`・`tasks.md`・`state.md`・`repo-map.md`）をAIの外部記憶として機能させることで、長期プロジェクトの管理コストを削減する設計
- CEO Agentとワーカーエージェントの書き込み権限（Write Scope）を明確に分離し、複数エージェントの同時作業時のファイル競合を構造的に防止
